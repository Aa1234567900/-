## 三、协调人：用数据替代口头反馈

让每位测试同学访问 **`链接?debug=1`**（例如 `https://e5b3cf9ee9e540e1ac392cf5e4a92154.app.codebuddy.work?debug=1`），
页面底部会出现"测试数据导出（debug）"面板：

- **刷新**：重新读取本次会话事件；
- **复制 / 下载**：把事件 JSON 发给你（或粘进共享文档）；
- **清空**：清掉本地事件，便于下一轮干净测试。

面板顶部"汇总"框会自动算出：
- 记录提交数；
- 每笔耗时 **中位数 / 平均**（毫秒）——对应验证线"≤5 秒"；
- 分类来源占比 **manual / auto / default**——对应"点分类 vs 自动分类比例"；
- 各页面浏览频次（可发现"进入记一笔却未提交"的流失）。

> 隐私说明：事件 JSON **仅含交互行为**（页面、耗时、分类 key、来源类型、Why 标签），**不含金额与备注文本**，可安全收集。

你把多份 JSON 汇总后发我，我可代为统计出上面的分布与异常点；或直接把单份 JSON 贴给我，我也能立刻定位问题。
